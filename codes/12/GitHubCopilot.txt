## Aim

To develop a **Python application using AI-assisted development tools such as GitHub Copilot, Cursor, or Claude Code**, following a **specification-first development approach**, and document how AI assistance was used during the development process.

## Algorithm / Procedure

1. **Define the application requirements**

   * Identify the problem to be solved.
   * Define the application's inputs and outputs.
   * Specify functional and non-functional requirements.
   * Define expected error handling and edge cases.

2. **Prepare the specification**

   * Create a `SPECIFICATION.md` file.
   * Document:

     * Project objective
     * Features
     * Input/output requirements
     * Classes and functions
     * Data structures
     * Validation rules
     * Error handling
     * Testing requirements
   * Treat this specification as the primary source of truth.

3. **Set up the Python project**

```text
ai-python-project/
│
├── SPECIFICATION.md
├── README.md
├── requirements.txt
├── app.py
├── tests/
│   └── test_app.py
└── AI_USAGE.md
```

4. **Configure an AI coding assistant**

   * Open the project in **GitHub Copilot, Cursor, or Claude Code**.
   * Provide the specification to the AI assistant.
   * Ask the assistant to generate code **according to the specification**.
   * Do not allow the AI tool to independently change requirements.

5. **Generate the initial implementation**

   * Ask the AI assistant to create the required Python classes/functions.
   * Ensure that the generated code follows:

     * PEP 8
     * Type hints
     * Appropriate exception handling
     * Modular design
     * The defined specification.

6. **Review AI-generated code**

   * Check the generated code manually.
   * Verify that every requirement in `SPECIFICATION.md` is implemented.
   * Identify incorrect assumptions or unnecessary code.
   * Modify the implementation where required.

7. **Generate tests using AI assistance**

   * Ask the AI assistant to create unit tests from the specification.
   * Include:

     * Normal cases
     * Boundary cases
     * Invalid inputs
     * Exception cases
   * Run the tests using:

```bash
pytest -v
```

8. **Validate the application**

   * Run static type checking if configured:

```bash
mypy .
```

* Execute the application:

```bash
python app.py
```

9. **Document AI assistance**

   * Create `AI_USAGE.md`.
   * Record:

     * AI tool used
     * Prompts provided
     * Code generated by AI
     * Human modifications
     * Testing performed
     * Problems identified in AI-generated code
     * Final validation results.

10. **Compare specification and implementation**

    * Verify every requirement.
    * Ensure no undocumented functionality was introduced.
    * Update the implementation if a requirement is missing.

11. **Document the project**

    * Update `README.md` with:

      * Project description
      * Installation instructions
      * Usage
      * Testing instructions
      * AI-assisted development process.

12. **Commit the completed project to GitHub**

```bash
git add .
git commit -m "Develop Python application using specification-first AI development"
git push origin main
```

## AI Documentation Format

The `AI_USAGE.md` file should contain:

```text
# AI Assistance Documentation

## AI Tool Used
GitHub Copilot / Cursor / Claude Code

## Development Approach
Specification-first development

## Specification
The application requirements were defined before implementation.

## AI Assistance
AI was used for:
- Code generation
- Test generation
- Code explanation
- Debugging
- Documentation

## Human Review
Generated code was manually reviewed and tested.

## Validation
- Unit tests: Passed
- Type checking: Passed
- Functional testing: Passed

## Final Status
The implementation satisfies the requirements defined in SPECIFICATION.md.
```
