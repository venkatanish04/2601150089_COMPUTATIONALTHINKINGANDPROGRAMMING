# Student Grade Management System

## Objective
Develop a Python application that stores student marks
and calculates the total, average, and grade.

## Requirements

1. Accept student name and marks.
2. Marks must be between 0 and 100.
3. Calculate total marks.
4. Calculate average marks.
5. Determine grade:
   - A: 90-100
   - B: 80-89
   - C: 70-79
   - D: 60-69
   - F: Below 60
6. Reject invalid marks.
7. Provide type hints.
8. Provide unit tests.
