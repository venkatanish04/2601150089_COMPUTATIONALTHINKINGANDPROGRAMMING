GitHub Copilot / Cursor / Claude Code

## Development Method

Specification-first development was used.

The requirements were written in SPECIFICATION.md
before implementing the Python application.

## AI Assistance

AI assistance was used for:

1. Generating the initial Python implementation.
2. Adding type hints.
3. Generating unit tests.
4. Identifying edge cases.
5. Explaining the implementation.
6. Improving documentation.

## Human Review

The generated code was manually reviewed to verify
that it followed the specification.

The following items were checked:

- Student validation
- Total calculation
- Average calculation
- Grade calculation
- Exception handling
- Type hints
- Unit tests

## Testing

The application was tested using Pytest.

Command:

pytest -v

## Validation

All specified requirements were checked against
the final implementation.

## Conclusion

AI assistance was used as a development aid, while
the final implementation and test results were
reviewed by the developer.
