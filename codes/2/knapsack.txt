## Algorithm / Procedure: 0/1 Knapsack using Dynamic Programming

### Algorithm: `KNAPSACK(W, wt[], val[], n)`

**Input:**

* `n` = number of items
* `wt[]` = weights of items
* `val[]` = values/profits of items
* `W` = maximum capacity of the knapsack

**Output:**

* Maximum possible value that can be placed in the knapsack.

### Procedure

1. Start with `n` items and knapsack capacity `W`.
2. Create a DP table `dp[n+1][W+1]`.
3. Initialize the first row and first column to `0`.

   * `dp[0][w] = 0` because no items are available.
   * `dp[i][0] = 0` because the knapsack capacity is zero.
4. For each item `i` from `1` to `n`:

   * For each capacity `w` from `1` to `W`:
5. If the weight of the current item is less than or equal to the current capacity:

   * **Include the item:**

     $$
     val[i-1] + dp[i-1][w-wt[i-1]]
     $$
   * **Exclude the item:**

     $$
     dp[i-1][w]
     $$
   * Store the maximum of these two values:

     $$
     dp[i][w] = \max(dp[i-1][w],\ val[i-1]+dp[i-1][w-wt[i-1]])
     $$
6. If the item's weight is greater than the current capacity, the item cannot be included:

   $$
   dp[i][w] = dp[i-1][w]
   $$
7. After filling the complete table, `dp[n][W]` contains the maximum achievable value.
8. Display the maximum value.

### Complexity Analysis

There are **n × W** entries in the DP table, and each entry takes constant time to calculate.

* **Time Complexity:** `O(n × W)`
* **Space Complexity:** `O(n × W)`

Where:

* `n` = number of items
* `W` = knapsack capacity

**Result:** The 0/1 Knapsack problem is solved using Dynamic Programming, where each item is either **selected (1)** or **not selected (0)**. The maximum profit is obtained without exceeding the knapsack capacity.

Sample Input
Enter number of items: 4
Enter weights: 2 3 4 5
Enter values: 3 4 5 6
Enter knapsack capacity: 5
Sample Output
Maximum value: 7

Time Complexity: O(n * W)
Space Complexity: O(n * W)
